This site is a browsable catalog of ir-datasets, a Python library that provides easy access to Information Retrieval (IR) datasets. It handles downloading, extracting, and reading source files, exposing document, query, and relevance judgment collections through a common interface, linked to one another in a graph.

Datasets are organized into three main types:

Data nodes are raw sources, like downloadable files. Examples: {{ node_code('irds:cranfield.tar.gz') }} {{ node_badge('irds:cranfield.tar.gz') }} and {{ node_code('irds:clueweb12.dir') }} {{ node_badge('irds:clueweb12.dir') }}

Tables parse Data into records with a consistent structure. Examples: {{ node_code('irds:msmarco-passage') }} {{ node_badge('irds:msmarco-passage') }} and {{ node_code('irds:trec-dl-2019-passage-qrels') }} {{ node_badge('irds:trec-dl-2019-passage-qrels') }}

Bundles are collections of Tables and other Bundles. Examples: {{ node_code('irds:antique-test') }} {{ node_badge('irds:antique-test') }} and {{ node_code('irds:bright') }} {{ node_badge('irds:bright') }}

Using it

import ir_datasets.v2
msmarco = ir_datasets.v2.load('irds:msmarco-passage')
len(msmarco)  # -> 8841823 (number of passages)
for psg in msmarco:  # loop over all passages
    print(psg.doc_id, psg.text)
msmarco.lookup('7067032').text  # look up a passage by its id
import pandas as pd
import pyterrier as pt
import ir_datasets.v2

dl19 = ir_datasets.v2.load('irds:trec-dl-2019-passage')

# index the passages
index = pt.terrier.TerrierIndex('msmarco-passage.terrier')
index.index({'docno': d.doc_id, 'text': d.text} for d in dl19.docs)

# evaluate BM25 on the TREC DL 2019 queries
queries = pd.DataFrame(dl19.queries).rename(columns={'query_id': 'qid', 'text': 'query'})
qrels = pd.DataFrame(dl19.qrels).rename(columns={'query_id': 'qid', 'doc_id': 'docno', 'relevance': 'label'})
pt.Experiment([index.bm25()], queries, qrels, eval_metrics=['ndcg_cut_10', 'map'])
