This site is a browsable catalog of ir-datasets, a Python library that provides easy access to Information Retrieval (IR) datasets. It handles downloading, extracting, and reading source files, exposing document, query, and relevance judgment collections through a common interface, linked to one another in a graph.

Datasets are organized into three main types:

Data nodes are raw sources, like downloadable files. Example: irds:cranfield.tar.gz

Tables parse Data into records with a consistent structure. Example: irds:msmarco-passage

Bundles are collections of Tables and other Bundles. Examples: irds:antique-test (a Benchmark) and irds:bright (a Suite).
